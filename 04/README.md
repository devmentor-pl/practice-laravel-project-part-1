# `#04` Laravel: Projekt cz. 1 (23-32)

Przenieś formularz dodawania wydatku do okna modalnego przygotowanego przy pomocy [Alpine.js](https://alpinejs.dev/).

Okno powinno się zamykać po naciśnięciu klawisza `Esc`, kliknięciu obok oraz przyciskiem. Typ wydatku wybieraj przy pomocy przycisków (zamiast pola `select`), a wartość przekazuj do ukrytego pola formularza.

Dodatkowo komunikat o poprawnym zapisaniu wydatku powinien znikać po 3 sekundach. Zadbaj o podstawowe atrybuty dostępności (np. `role="dialog"`, `aria-labelledby`).
